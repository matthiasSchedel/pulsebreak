# Pulsebreak public artifact

This repository serves the static Pulsebreak game, marketing page, support page, and privacy policy for the App Store listing.

- Game: <https://matthiasschedel.github.io/pulsebreak/>
- Support: <https://matthiasschedel.github.io/pulsebreak/support/>
- Privacy: <https://matthiasschedel.github.io/pulsebreak/privacy/>

The artifact has no server runtime, analytics, ads, tracking pixels, remote fonts, or required cross-origin dependency. Product source and delivery evidence are maintained in the private `matthiasSchedel/gauntlet-survivor-lite` repository.
